# Compatibility

This fork intentionally supports only **WarioWare Gold for Nintendo 3DS**.

| Game | Region | Title ID | Support |
|---|---|---|---|
| WarioWare Gold | USA | 00040000001D1C00 | Supported by title filter |
| WarioWare Gold | Europe | 00040000001D1C00 | Supported by title filter |
| Made in Wario Gorgeous | Japan | 00040000001D1C00 | Supported by title filter |

The retail releases use the same title ID. The WarioWare Gold demo uses a different ID and is not included. All other Nintendo 3DS titles are filtered out of the library and rejected when started directly.

“Supported” here means the retail title is accepted by the title filter; it is not a claim that every microgame, microphone input, touchscreen interaction, motion input, or other feature has been fully tested. A decrypted game dump is required. The title-specific recompiled output is generated locally and is not distributed with the project.
